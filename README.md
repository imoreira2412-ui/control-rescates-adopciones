
# Sistema de Control de Rescates y Adopciones

## Descripción
Este proyecto consiste en el diseño lógico de un sistema para gestionar el rescate de animales y facilitar sus procesos de adopción.

## Objetivo
Diseñar la arquitectura del sistema mediante diagramas UML, aplicar patrones de diseño y utilizar GitHub con el flujo de trabajo Gitflow para organizar los cambios del proyecto.

## Contenido del proyecto
- Análisis del escenario y requisitos del sistema.
- Diagrama UML de casos de uso.
- Diagrama UML de clases.
- Aplicación de patrones de diseño creacionales, estructurales y de comportamiento.
- Control de versiones con GitHub y Gitflow.

## Herramientas utilizadas
- diagrams.net para los diagramas UML.
- GitHub para el repositorio y el control de versiones.
